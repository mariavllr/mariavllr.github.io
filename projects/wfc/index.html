The challenge

Procedural worlds often look either random or repetitive. Wave Function Collapse works from local rules: which tile may sit next to which. From those rules alone, it builds a whole map that is coherent everywhere.

My research asks how to keep that output feeling hand-made, and how to give artists real control over a world that builds itself.

How WFC works try it!

The only rule: colours must match across every shared edge.

  1. Superposition. Every cell starts as all four tiles at once. The small tiles inside a cell are the ones it could still become.
  2. Observe. Pick the cell with the fewest options left, its lowest entropy, and collapse it to one of them at random.
  3. Propagate. Neighbours drop every tile whose edge doesn't match.
  4. Repeat until every cell has one tile. If a cell is left with no tile that fits, that's a contradiction, and the solve starts again.

Press Step, or click a small tile to choose it yourself.

Tileset and walkthrough adapted from Wave Function Collapse Explained by Boris the Brave.

My work

  • A tile set modelled in Blender, designed so every edge matches its neighbours: coast, cliffs, rivers, paths and houses.
  • A WFC solver in Unity with weighted tiles, border constraints and fast regeneration.
  • Generation in layers (ground, sky…).
  • A socket system: every tile edge has a socket, so valid neighbours and rotated variants are generated automatically instead of being set up by hand.
  • An interactive mode with a tile queue, drag-and-drop placement, live highlighting of valid spots and cascading collapse after each move.
  • A game prototype with points and missions based on which tiles end up next to each other.
  • Global constraints, such as fixed tiles, rivers, or paths that connect villages, on top of the local rules between neighbours.
  • Optimisation of the algorithm for 3D grids.
